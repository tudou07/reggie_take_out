This project is a food delivery ordering system, consisting of a backend system and a mobile application.

Backend system:
Dish management (batch deletion, activation/deactivation of items);
Set meal management (modification, activation/deactivation of packages);
Order details and related functions.

Mobile app:
Personal center (logout, latest order inquiries, historical orders, address management - modify/delete addresses);
Shopping cart (remove items) and other features.
